# MediCenter Web

Астанадағы клиникаларға онлайн жазылу, TOPSIS/SAW рейтингі және AI талдау — телефонға орнатылатын веб-қосымша (PWA).

**Ашу:** https://sarsenbayeljan-bit.github.io/medicenter-web/

Бұл репозиторийде тек дайын (жинақталған) веб-қосымша бар. Windows нұсқасы: https://sarsenbayeljan-bit.github.io/medicenter-download/

## Анатомия атласы · лицензия

`atlas/` қалтасындағы 3D анатомия моделі — [Z-Anatomy](https://www.z-anatomy.com/) (BodyParts3D негізінде),
лицензиясы [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Модель жеңілдетілген (үшбұрыш саны азайтылған,
текстурасыз) және 11 аймаққа бөлінген; өзгертілген нұсқа (`atlas/atlas.bin`, `atlas/index.html`) сол CC BY-SA 4.0
лицензиясымен таратылады. Атлас оқу мақсатына арналған, медициналық кеңес орнына жүрмейді.
